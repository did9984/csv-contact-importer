# 学習目標と検証記録

## 目標

CSV一括登録APIを開発し、事前検証・エラー報告・全件成功または全件失敗となるトランザクション処理を実装する。

## 完了基準

- [ ] サンプルCSVで検証プレビューと実際の登録を実行する。
- [ ] 検証エラー、ファイル内の重複、DB内の重複に対するエラー報告を説明する。
- [ ] 統合テスト8件で、全件保存または保存0件の処理と、同時登録時のデータ整合性を確認する。
- [ ] READMEの手順でアプリを起動し、サンプルのAPIリクエストを再現する。
- [ ] テストログと理解した設計内容を、評価の根拠資料として整理する。

## 実装済みの検証

検証プレビュー、実際の登録、不正な行がある場合の保存0件、大文字・小文字を区別しない重複検出、CSV構文・UTF-8のエラー、BOM、行数上限を検証します。共通のメールアドレスを含む2つのCSVを同時登録し、失敗したファイルの一部の行もDBに残らないことを確認します。
